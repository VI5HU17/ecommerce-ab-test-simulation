# E-Commerce A/B Test Simulation Framework

## Overview
This repository contains an end-to-end Product Management and Data Analysis project evaluating the business impact of a simulated e-commerce A/B test. 

The project models the trade-off between user friction and security by testing a "Guest Checkout" feature against a traditional forced-account creation flow. It features:
* A Product Requirements Document (PRD) defining the core hypothesis and business metrics.
* An Object-Oriented C++ engine that simulates 20,000+ user sessions with variance and probability weighting.
* Data analysis measuring primary conversion rates, time-to-checkout, and counter-metrics like fraud flags.

**Core Skills Demonstrated:** Product Strategy, C++ (OOP), Data Generation, Statistical Significance (A/B Testing), and Business Risk Assessment.
